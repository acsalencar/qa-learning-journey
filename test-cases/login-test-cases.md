# Login Test Cases

## TC01 - Valid Login

Steps:
1. Navigate to login page
2. Enter valid email
3. Enter valid password
4. Click login

Expected Result:
User is redirected to dashboard.

---

## TC02 - Invalid Password

Steps:
1. Navigate to login page
2. Enter valid email
3. Enter invalid password
4. Click login

Expected Result:
Error message is displayed.
